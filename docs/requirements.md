
# BugHunter Shop – Software Requirements

## Project Description
BugHunter Shop is a demo e-commerce application
created for learning software quality assurance.

## Functional Requirements

FR-001: Users can log in with valid credentials.

FR-002: Users receive an error message when login
credentials are invalid.

FR-003: Users can view available products.

FR-004: Users can add products to their shopping cart.

FR-005: Users can remove products from their cart.

FR-006: The shopping cart calculates the correct
total price.

FR-007: Users can complete checkout after providing
all required information.

FR-008: Users cannot complete checkout when
required information is missing.


FR-009: The checkout postal code must contain
exactly five numeric digits.

The application must reject postal codes
containing letters, special characters,
or an incorrect number of digits.

Accepted example: 71000
Rejected examples: ABCDE, 123, 123456, 71A00


## Project Scope

This application is for educational testing only.
No real payments or personal customer data are used.
