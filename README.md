
# BugHunter QA Lab

A Quality Assurance portfolio project focused on manual and automated software testing.

## Project Overview

BugHunter QA Lab is a web application testing project designed to demonstrate practical QA skills through intentionally introduced software defects.

## Project Goals

- Design and execute manual test cases.
- Identify, reproduce, and document software bugs.
- Perform positive and negative testing.
- Develop automated tests.
- Generate test execution reports.
- Practice professional QA documentation.
